# Sankofa06 portfolio

Static portfolio site for `https://sankofa06.github.io/`.

The site intentionally describes the work without requiring each source repository or live system to be public. Private operational tools are represented by sanitized case studies rather than public demos. The site has no build step, external dependencies, analytics, cookies, or runtime configuration.

## Local preview

Open `index.html` directly or serve the directory with any static HTTP server.

## Publishing

Publish this repository as `Sankofa06/Sankofa06.github.io` with GitHub Pages serving the `main` branch root.
