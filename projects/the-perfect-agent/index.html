PHONE DELIVERY

“Test this on my phone.”

A separate one-shot lane, pinned to an exact candidate and the app repository’s real release contract.

What stays out

Less context.
Fewer contradictions.

Development stacks

Swift, Unreal, web, Git, and release commands belong to the repository that can keep them true.

Private history

No raw chats, secrets, hidden reasoning, personal finance, or infrastructure identities become memory.

Unattended mutation

Recurring automations may observe and report, but they do not modify code or release builds.

Permanent lessons

Shared and persona memory have hard caps, review dates, expiry, and deletion triggers.

Portable by design

Copy the framework.
Keep the project specific.

Adopt the governing files and workforce skill, then let each repository define its own commands, architecture, verification, and delivery route.
